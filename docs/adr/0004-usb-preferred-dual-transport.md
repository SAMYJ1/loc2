# 同一手机的 USB 优先双通道

2026-11-02，用户要求同时支持 USB 和无线，并明确 USB 必须同时承担手机控制和位置报点，使关闭手机 Wi-Fi 后仍可操作 Mac。这更新 ADR-0002 的日常无线优先方向；控制端与执行端分离、明确应用、不自动重放目标的约束继续保留。

两种报点通道共用原已配对手机的逻辑身份；USB 只选择本机已绑定设备的 USB 标识，不把其他插线设备视为该手机。每次明确应用时优先 USB，未接 USB 时才使用无线。插拔造成报点通道变化时结束旧会话，用户重新应用才启动新会话；不同时向两条链路供数，也不在 USB 启动失败后静默改用无线。

USB 控制采用仅绑定手机本机回环地址的转发入口，由 Mac 通过 usbmux 连接所选实体 USB 设备。控制请求仍由现有 HTTPS 服务处理，沿用 Mac 证书指纹、证书主机名及配对令牌校验；USB 只替换传输地址，不降低身份校验。手机控制请求优先 USB，断开后可恢复局域网控制，但不自动重试具有副作用的应用／停止操作。手机退后台或关闭不结束 Mac 持有的报点会话；回到前台后读取实际状态。

同日用户进一步要求一台 iPhone 保存多台 Mac 并自动尝试可用电脑，跨电脑的选择与会话归属规则见 [ADR-0005](0005-multiple-paired-computers.md)。
