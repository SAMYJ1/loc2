# 原生手机控制端与 Mac 后台执行服务

2026-10-30，用户提出将地图搜索、选点、收藏、系统报告位置观察及恢复流程集中到原生手机 App，Mac 只保留后台执行和必要调试入口；此前无线隐藏链路已有短时成功证据，因此拟以无线方式作为日常链路。该方向取代 ADR-0001 中 Safari 主入口及 USB 独占执行通道的边界，同时保留控制端与执行端职责分离、明确应用和会话结束不自动重放等规则。

原生端增加安装维护与平台权限成本，但可提供直接的系统位置观察闭环，减少切换其它地图 App 的日常操作。用户已完成最终需求确认，本ADR现已接受；ADR-0001中的职责分离规则保留，手机入口与USB独占边界由本决策替代；无线应用集成、首次配对、后台及长期稳定性仍待实现和验收。

首轮访谈已确认：Mac默认手动开启、自启动可选；手机在Mac不在线时仍能管理地图、收藏和草稿；关闭手机App不等于停止会话，前台恢复时读取实际状态。首次配置优先无线，首版采用免费开发签名，付费与上架后续再评估。

第二轮已确认单地图主界面、收藏和最近使用、单击恢复与恢复状态分层、报点期间保持Mac免于普通闲置睡眠，以及2小时长时验收目标。全部使用体验问题及最终共同理解均已确认，进入实现。

2026-11-02：用户进一步要求 USB 和无线都支持控制与报点，并优先 USB；该通道选择由 [ADR-0004](0004-usb-preferred-dual-transport.md) 更新。
