# 同一手机保存多台电脑并自动选择

2026-11-02，用户要求同一台 iPhone 保存多台 Mac，当前电脑不在可用范围时自动尝试另一台。手机保存各电脑独立的证书指纹、授权凭据和名称，兼容原单电脑钥匙串记录；相同主机名不能合并不同证书身份。每台新电脑仍通过扫码与 Mac 端批准建立授权。

自动发现仅查询状态：已有活动会话的电脑可达时保持归属；否则优先匹配 USB 上已配对电脑，再保持当前可用的局域网电脑，最后有界并发尝试其他已配对电脑。USB 与局域网是显式路由，USB 接到另一台电脑不会阻断当前电脑的独立局域网探测；TLS 指纹、主机名和令牌校验不因自动切换而降低。

应用、恢复等有副作用的请求绑定发起时的电脑，不跨电脑重试。发送应用请求前先持久记录可能存在的会话，以覆盖请求已到达但响应丢失的情形。原电脑不可达且可能仍在报点时，可以自动连接另一台并查看状态，但在确认旧会话停止前不启动另一台报点。恢复观察与未确认会话按电脑隔离；读到原电脑已停止后自动清除待确认记录，或由用户在原电脑停止后明确确认。
