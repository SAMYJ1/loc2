# 手机控制与 USB 定位会话分开

2026-10-29，用户决定第一版仅供自己的单台 Mac 与 iPhone 使用：手机选点请求可以通过同一 Wi-Fi 传给 Mac，Mac 仍通过已实测的 USB 配件链路报点。Mac 只在首次配对授权时要求人工确认，之后由手机直接应用目标；手机页面切后台不结束已经接受的会话，而 USB 断开、Mac 睡眠或应用退出会结束会话，重连后需重新发起应用。

该划分避免把手机网页的生命周期当作持续位置数据源，也避免为了手机选点而重做目前未验证成功的无线定位或新增原生 iPhone App 的 USB 通道。用户进一步确定授权持久保存并可在 Mac 撤销；未接线时可准备选点草稿，USB 就绪后仍需在手机明确点击应用。

2026-10-30：原生手机入口与无线日常链路的新方向已确认，相关边界由[ADR-0002](0002-native-phone-control-and-mac-service.md)更新；控制端与执行端分离、明确应用与不自动重放的约束继续有效。
