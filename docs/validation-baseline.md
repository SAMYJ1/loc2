# USB 实测基线

记录日期：2026-10-29。来源：本项目应用化之前的真机研究记录。

## 已有行为证据

同一 Mac 与 iPhone，iOS 27.0 (24A435)，USB 配件链路使用相同身份及固定测试点。开发者模式开启与关闭组均由系统直接查询核对；两组都观察到测试位置。关闭组在没有再次开关定位服务时，Apple 地图到达并稳定在测试点；停止后的不同时刻，Apple 地图和高德显示变化不同步。拔线并刷新定位服务后，两者恢复真实位置。

本地位置队列记录：开启组 97 组／194 条，关闭组 69 组／138 条。这是本地接受或入队计数，不是逐包手机解析证明。

## 证据边界

- 关闭组紧接成功的开启组，并复用配件身份，不能排除初始化或状态保留影响。
- 尚未采集原生 CLLocation 时间戳及来源字段；没有证明所有 App、全新设备或其他系统版本兼容。
- 手机网页控制、持续会话切点、隐藏 CarPlay 画面、锁屏与长时间运行尚未验证。
- 停止报点与恢复真实位置不是同一事件，恢复需要单独确认。
- 已测试的同网无线定位没有确认成功，iPhone 热点拓扑未建立网络 CarPlay，因此第一版采用 USB 提供位置。
- 现有实验依赖此前用户授权的第三方实验配件身份；本仓库不包含认证文件、密钥、配对记录或运行时。

完整日志、结构化结果与实验控制器保留在原本机调研工作区。本仓库目前只保存设计及这份脱敏证据摘要，不代表已经交付可运行应用。
