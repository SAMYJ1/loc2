## 开发检查

- 会话服务、授权、收藏与地图策略的公开行为测试。
- 浏览器首次配对、明确应用、草稿隔离、停止、授权撤销、收藏与地图回退流程。
- 原生应用编译和本地签名。
- 集成分支相对 main 的规范与规格审查，修复后复测。

替身接收器、替身地图 SDK 和回环地址上的浏览器测试只能证明对应的软件行为。它们不能证明 Safari、实际局域网、第三方配件链路或手机位置采用。

## 现场开始前

- 准备目标 Mac、iPhone、USB 线和同一局域网。
- 在本机准备此前已获授权的配件身份和隔离运行时；原实验目录保持不变。
- 提供受限 Maps 页面令牌；签名私钥留在本机，不能作为页面令牌使用。
- 选择可独立核对的参照点 A/B，并在测试开始前记录允许误差、持续运行时长和观察方式。
- 记录应用提交、Mac/iOS 版本、是否处于预期网络环境和真实位置基线。设备标识、配对资料、网络凭据和精确原始轨迹留在本机。
